Hotspot Setup Script (MikroTik RouterOS)

Pakua .RSC File

Nakili maagizo haya na uyabandike kwenye Terminal ya Winbox / SSH ya MikroTik yako kusanidi Walled Garden, Hotspot Profile na Rate Limits: 

/ip pool add name=hs-pool-1 ranges=192.168.88.10-192.168.88.254
/ip address add address=192.168.88.1/24 interface=bridge
/ip hotspot profile add dns-name="wifi.hotspot" hotspot-address=192.168.88.1 name=hsprof-speedwave
/ip hotspot walled-garden add dst-host="*.safaricom.co.ke"
/ip hotspot walled-garden add dst-host="*.airtel.com"

RADIUS Configuration Script

Pakua RADIUS .RSC 
/radius add address=192.168.88.1 secret="SpeedWaveSecretKey2026!" service=hotspot
/radius incoming set accept=yes port=3799
